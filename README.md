# Dodgy Dublin Redemption

Created by **Matheus Amud**.

A retro side-scroller through Dublin city centre, from Capel St to Stephen's Green.
Stomp seagulls, punch scumbags, wait for the green man, dodge the Luas and the Garda chases,
save your bike from the thieves, and beat the Big Gull.

**Play:** open the GitHub Pages link on your phone, turn it sideways, tap Start.

## Install it on your phone like an app

- **iPhone (Safari):** tap the Share button, then **Add to Home Screen**.
- **Android (Chrome):** tap the ⋮ menu, then **Install app** (or **Add to Home screen**).

It then opens full-screen from the gull icon and works offline after the first visit.

## Controls

- Phone: ◀ ▶ to walk, JUMP, PUNCH (turns into TALK / BUY / GIVE near friendly people)
- Keyboard: ← → or A D to walk, Space / W / ↑ to jump, J or X to punch or talk, M for sound

## Publishing an update

1. Replace `index.html` with the new version.
2. Open `sw.js` and bump the version, e.g. `dodgy-dublin-v1` → `dodgy-dublin-v2`.
3. Commit. Phones pick up the new version next time the game is opened with a connection.
